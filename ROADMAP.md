# Roadmap — Claude Deck

Каждый видимый элемент обязан быть **гиперссылкой** в исходную систему (ветка→GitLab, MR→страница MR, сборка→TeamCity, задача→Jira).

## Фаза 0 — Bootstrap
- [x] Прототип UI/UX (`prototype/index.html`), опубликован как Artifact.
- [x] Выбрана база форка: `nimbalyst/nimbalyst` (MIT, Electron/TS, кроссплатформа).
- [ ] Форк на GitHub → `github.com/kioflex12/claude-deck`, клон локально, сборка на Windows (`npm i && npm run dev`).
- [ ] Перенести дизайн-токены/лейаут прототипа в UI nimbalyst.

## Фаза 1 — Данные (read-only), убить «неудобную навигацию»
- [ ] Доска по задачам WO: колонки TODO / In Progress / Review-QA / Done.
- [ ] Читать привязку задача↔сессия↔ветки↔MR из `dev-workflow/WO-XXXX.json`.
- [ ] Статус задачи из Jira (mcp-tools / REST).
- [ ] Статусы сборок Android/iOS из TeamCity + deep-link в билд.
- [ ] Статусы MR из GitLab + ссылка на MR.
- [ ] Обвязка всего ссылками.

## Фаза 2 — Сессии
- [ ] Привязка карточки к сессии Claude; «Продолжить» → `claude --resume` (движок nimbalyst).
- [ ] Полноэкранная сессия: чат слева + рейл справа (по прототипу).
- [ ] Индикатор окна контекста (токены) + «форкнуть чистую сессию».

## Фаза 3 — Скиллы и MCP
- [ ] Вкладка «Скиллы»: индексировать `.claude/skills/*/SKILL.md` (frontmatter name/description + триггеры), категории, поиск, вставка `/команды`.
- [ ] Вкладка «MCP»: список серверов, активные / ждущие авторизации, активация коннекторов.

## Фаза 4 — Ускорители (по приоритету пользователя)
- [ ] Командная палитра Ctrl K (задачи / скиллы / MCP / виды).
- [ ] Лента «Требует внимания» (красные сборки, незакоммичено, device-verify, блокеры).
- [ ] Статус окружений squad/preprod/preupdate (k8s/api).
- [ ] Монитор сборок TeamCity (идёт/очередь/упала).
- [ ] Быстрые действия на карточке (отчёт в Jira, создать MR, форк, деплой).

## Известные ограничения окружения
- `gh` CLI не установлен (git есть). Создание удалённого репо + push — через установку `gh` или вручную на GitHub.
- Разработчик на Windows → база форка обязана собираться на Windows (nimbalyst — да).
