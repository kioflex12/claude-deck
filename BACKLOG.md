# Deck — бэклог

## Цель: уйти от концепта → десктоп-приложение (Electron)

Решено 2026-07-27: паковать Deck в настоящее десктоп-приложение на **Electron** (не Tauri —
бэкенд `server.mjs` + Agent SDK это Node, а Electron-main и есть Node, переиспользуется как
есть; Tauri потребовал бы Node-сайдкар). Своя тонкая оболочка, без чужих trust/consent-гейтов.

**Зависимость (неустранимая):** на машине всё равно нужен установленный и залогиненный
Claude Code CLI — SDK шеллит его и берёт OAuth из `~/.claude`. Electron бандлит Node, но не `claude`.

### DESKTOP-1 — MVP-оболочка (первый шаг, самый ценный)
`electron/main.js`: на старте поднимает `server.mjs` на свободном localhost-порту, открывает
`BrowserWindow` на этот URL. Переиспользует весь текущий код (index.html + server.mjs) без
переписывания. Иконка, своё окно — без терминала и вкладки браузера. `electron-builder` →
инсталлятор под Windows (и macOS). Мелкий рефактор `server.mjs`: выбор свободного порта +
экспорт старт-функции. Проверить Agent SDK в Electron-main (не выставлять `ELECTRON_RUN_AS_NODE`).

### DESKTOP-2 — как настоящее приложение
Трей-иконка, автозапуск при входе, single-instance lock, запоминание размеров окна, нативное
меню, нативные уведомления (сейчас веб → системные).

### DESKTOP-3 — дистрибуция
Установщик (NSIS для Win, dmg для macOS), версия + автообновление. Подпись/нотаризация macOS
(можно отложить — локально работает и без).

## TECH — качество кода (параллельно / фаза D4)

### TECH-1 — Рефакторинг монолитного index.html
`index.html` — одно полотно ~2000+ строк (разметка + весь CSS + вся логика). Разнести на
нормальную структуру: отдельные CSS/JS-модули (ES modules), тонкий HTML-шаблон, компоненты
(доска/карточка/session-view/composer/rail/палитра/скиллы/MCP/usage). Общий data-fetch слой в
один модуль. Дизайн 1-в-1. Прикинуть разбивку `server.mjs` по доменам (sessions / chat+SDK /
integrations TeamCity+GitLab+Jira / static). Крупная структурная работа — отдельным заходом.

### TECH-2 — Динамические списки из Claude ✅ СДЕЛАНО

реального окружения при загрузке; хардкод `SKILLS`/`MCP_SERVERS` убран; палитра на тех же данных.

### TECH-3 — Перф `/api/sessions`

mtime — перечитывать только изменённые файлы.

### TECH-4 — Надёжность
Много «тихих» `catch {}`; падения TeamCity/Jira/GitLab показывать, а не глотать; ретраи/бэкофф.
Чистый data-flow (убрать латание кэш-гонок точечными фолбэками).

### TECH-5 — Тесты
